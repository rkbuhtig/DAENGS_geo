중심 기록과 연결 관계는 유지하고, HOW 정의는 한 번만 전달한다. 전체 근거는 툴에 보관한다.

합성 7조건 · 기존 스탬프 후보 전체 고정 · 모델 호출 0회 · 문장 생성 전

전체 작성 입력 · UTF-8 JSON
전달하는 HOW 정의
이번 비교의 구성스탬프 순서·중심·연결 관계 고정
같은 방식으로 공백을 제거한 입력 JSON 바이트를 비교했다. 프롬프트와 응답 스키마는 동일하며, 토큰·비용·문장 품질 측정값은 아니다.

기존 작성 입력

판정 구간·세부 수치·긴 참조가 스탬프마다 반복



짧은 작성 입력
종류별 핵심 값 + 짧은 HOW 참조 + 원래 연결 관계




참조가 가리키는 원본 근거
회색: 원래 동선 · 보라: 선택한 HOW 판정 구간 · 주황: 스탬프 대표 지점


선택 스탬프의 HOW 참조
짧은 참조를 누르면 툴에 남겨 둔 긴 구간과 수치를 확인할 수 있다.


원본 기록·시각 유지역할·시간 관계 유지방향·불확실성 유지
사진은 사진 시각에 남는다. 체류의 관측 구간 길이와 기록의 지속시간을 구별하고, 미확정된 회전 시각·사건 순서는 미확정으로 전달한다.


툴에 보관된 원본 HOW


로컬 버전·참조 명세


기존 작성용 투영과 새 작성용 투영을 비교하는 화면이다. 원본 GPS는 두 입력 모두에 포함하지 않는다. WHERE·행동 관계의 별도 압축과 실제 LLM 작성 비교는 이번 실행에 포함하지 않았다.
