# WalkDiaryRoute는 익명화 파생이 아니며 서버 영속을 아직 열지 않는다

결정 #79의 WalkJournalProjection은 시간·거리·Pin을 글로 다시 읽지만, 단일 산책의 동선은
없다. 날짜 하나를 보는 일기는 시작·종료·사건 순서와 속도 같은 미시 흐름을 선으로 읽을 때
완성도가 높아진다. 반면 결정 #57과 #69는 연속 궤적을 finish 뒤 서버에 남기지 않는다.

[측정](../research/2026-09-03-walk-diary-route-privacy.md)에서 앞뒤 누적 거리 60m를 잘라도 산책
중간에 시작점을 다시 방문한 선이 원점 1.79m까지 노출됐다. 공간 반경과 교차하는 선분을 전부
자르면 직접 재방문은 가릴 수 있었지만, 짧은 예제에서는 60m만으로 경로의 63.1%가 사라지고
100m에서는 표시할 선이 하나도 남지 않았다. 반복 산책의 빈 중심 추론도 아직 재지 않았다.

## 결정 1 — 제품 방향은 열되 서버 저장 계약은 열지 않는다

단일 세션을 선으로 읽는 UI 방향은 유지한다. 그러나 현재 `WalkDiaryRoute` 후보를 DB·API·
Capsule manifest 자식으로 추가하지 않는다. #69의 단순화 궤적 영구 저장 금지와 #57의 구체
보관 기간 게이트는 그대로다.

현재 허용 범위는 dev Lab, fixture replay, 기존 원본 수명을 늘리지 않는 종료 직후 미리보기다.
빈 후보는 빈 산책이 아니라 `unavailable`이다. 과거 purged 세션에 선을 지어내지도 않는다.

## 결정 2 — 앞뒤 거리 절단을 보호 정책으로 쓰지 않는다

향후 후보의 시작·종료 보호는 경로 순서의 첫 N미터·마지막 N미터가 아니라 **시작·종료 좌표
주변 공간과 교차하는 모든 구간**을 대상으로 한다. 중간 재방문, 루프, 왕복도 같은 규칙을 탄다.

- 점만 제거한 뒤 양쪽을 직선으로 잇지 않는다.
- 보호권 진입·이탈마다 fragment를 끊고 redacted gap을 표현한다.
- CanonicalTrail의 gap·jump·accuracy 거부·pause chain도 절대 다시 잇지 않는다.
- 저장 후보에 보호권 중심인 원 start/end 좌표를 메타데이터로 싣지 않는다.

반경 60m·100m는 실험점이지 채택값이 아니다. 실제 기기와 사용자 열람에서 정보 손실을 재기
전까지 전역 기본값을 두지 않는다.

## 결정 3 — 양자화와 단순화는 최소화이지 개인정보 보장이 아니다

보호권 경계가 아닌 내부점의 5m 양자화와 5m 단순화는 600m 직선 예제의 표시 점을 101개에서
2개로 줄였다. 정확한 원 경계 교차점은 격자 밖 예외로 남기고 profile에 그 범위를 명시한다.
이것은 저장량과 시각 디테일을 줄이지만 시작점 노출을 스스로 막지 못한다. 따라서 `privacy-reduced`,
`anonymized` 같은 안전 주장을 이 두 연산만으로 붙이지 않는다.

공간 보호를 적용해도 여러 세션을 겹쳐 빈 원의 중심을 추정할 수 있다. 채택된다면
WalkDiaryRoute는 Cellophane보다 안전한 무좌표 통계가 아니라 **private coordinate-bearing
artifact**다. 세션 삭제·subject 삭제를 따라야 하고, 공개·공유는 별도 위치 마스킹 결정 없이
열지 않는다.

## 결정 4 — 후보 형태는 시간 순서와 단절을 보존한다

다시 열 때의 최소 후보는 session ID, source calculation version, privacy profile version,
순서 있는 fragment, 각 점의 elapsed offset, edge별 coarse speed band, gap 이유다. 절대 시각과
세밀한 순간 속도를 그대로 복사할 이유는 없다. 정확한 speed 문턱·평활·hysteresis는 이 결정이
채택하지 않는다.

이 결과는 단일 세션 일기 전용이다. 조건별 여러 세션은 계속 Cellophane 면 중첩으로 읽는다.
WalkDiaryRoute를 Cellophane 통계, Memory Place 분모, 점령 Encounter·Capture 판정에 쓰지 않는다.

## 다시 여는 조건

- 실제 Android trace로 반경·양자화·단순화의 정보 손실과 사용자 열람 가치를 함께 측정한다.
- 여러 날짜를 겹친 공격에서 보호권 중심과 생활 거점의 추론 위험을 측정한다.
- 서버 또는 기기 중 저장 위치, 구체 보관 기간, 종료 후 저장/버림, 세션·subject 삭제 UI를
  하나의 수명 계약으로 정한다.
- 속도 band가 GPS 노이즈를 행동 의미처럼 과장하지 않는지 실제 기기에서 검증한다.
