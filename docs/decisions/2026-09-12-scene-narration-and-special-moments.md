# 결정 #88 — 장면·행동 서술과 특별한 순간

날짜: 2026-09-12. 기획 채택이며 실제 지정 API 분류·새 서술 품질·운영 연결은 미완료다.

[결정 #87의 장면 우선 기획](../explorations/walk/diary/plan.md)을 후속 사용자 대화로 구체화한다.
결정에 도달한 경위·철회된 접근·실제 실험·대화 출처는
[상세 인계 묶음](../explorations/walk/diary/narrative-design/README.md)에 남긴다.

## 결정

1. 일반 장면의 서술은 **어디서·누가·무엇을·어떻게·환경 α**의 의미 관계를 바탕으로 한다.
   무엇을과 어떻게를 구별하며, 모든 자리를 채우거나 같은 문장 틀로 쓰는 형식은 아니다.
2. 공간·환경을 그리는 장면 서술과 행동을 가까이 담는 서술의 역할을 나눈다. 이것이 두 모델·
   두 본문·고정 접합을 요구하지는 않는다. 공간의 조망 시선과 행동의 주체를 구별하고 내면을 만들지 않는다.
3. **특별한 순간의 자유 서술은 기록마다 별도 장면을 보장하고 AI가 본문에 관여하지 않는다.**
   그 순간의 공간·환경 정보만 원문과 구별해 제공한다. 자료 부족·장면 수·API 실패로 합치거나 버리지 않는다.
4. 행동 핀은 반려견의 기록된 행동을 중심으로 쓴다. 함께 나온 참여 대상과 핀의 실제 행위자를
   구별한다. 행위자 필드의 후속 구현을 이유로 서술 전략·문장 비교를 미루지 않는다.
5. 실제 지정 API를 한 좌표에서 호출해 반환 필드·범위·결측을 읽고 골격에 분류한 뒤 같은 기준을
   다른 좌표에도 적용한다. 다른 API·과거 자료·가상 예문으로 이 검증의 완료를 대체하지 않는다.
6. 실제 모델 입력·목적·프롬프트·원문 응답을 먼저 보여주고 서술 품질을 판단한다. 형식·인용 검사나
   슬롯 구현, 앱 적용을 좋은 문장의 증명으로 보고하지 않는다.

## 이유

기존 작업은 사실 오류를 줄이면서 시설명과 거리의 고정 문구로 좁아졌다. 원문을 뒤에 붙이거나
근거 ID를 검증했어도 사용자가 돌아볼 장면이 좋아졌다는 증거는 아니었다. 이후 전체 시간순
맥락을 더 제공한 실험에도 근거 없는 밤 풍경·연속성·행동이 남았다.

사용자는 장면 자체의 완성도를 우선하면서 자유 서술과 행동 핀을 다르게 다루고, 서술에 필요한
의미 역할을 실제 API가 주는 자료로 검증하라고 요청했다. 자료를 잘 모았다는 설명에서 끝나지
않고 그 자료가 읽을 만한 글이 되는 과정을 확인하기 위한 결정이다.

## 유지하는 경계와 반영 범위

전체 세션 이해와 시간순 장면 재검토를 필수로 두지 않는 #87을 유지한다. 원시 시간·순번은
장면의 자유 추론 입력으로 주지 않고 시스템의 판정·정렬에 보존한다. 준비 뒤 한 결과 공개,
늦은 AI의 공개본 교체 금지, 사용자 편집 우선도 유지한다. 전체 일기는 별도 후속 생성이다.

3/1/1·250m·30초 같은 기존 실행값을 이 결정으로 최적 정책에 승격하거나 조정하지 않는다.
구체적 화자·분량·모델·호출 묶음·본문 계약은 실제 결과로 정할 구현 선택이다.

특별한 순간을 일반 재작성 대상에 포함하는 과거 예시와, 모든 기록을 동일 배경 조립으로
다루는 과거 구현 설명은 현재 서술 지시로 사용하지 않는다. 당시 연구 결과는 보존하되
현재 기획 입구와 각 관련 문서에서 이 결정으로 연결한다.
