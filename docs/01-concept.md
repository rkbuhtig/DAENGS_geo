# 01. 컨셉

## 담당 범위

팀 기능 목록 중 이 레포의 관할은 두 개.

- 병원/약국 찾기 AI
- 게임(산책)

생활관리 · 훈련비서 · 보행체크 · 체형진단 · 피부/안구 진단은 **타 담당**. 증상 문진 챗봇도 관할 밖 (생활/훈련 챗봇과 경계가 붙어 있어 선을 긋는다).

## 산책 게임의 방향

산책의 현실은 **매일 같은 길**이다. 콘텐츠(맵·퀘스트·세계관)로 이걸 이기려 하지 않는다.

- **판타지 레이어 없음.** 심해탐사·폐허도시 같은 테마 씌우기 폐기.
- 에이전트는 **개의 목소리**다. 프로필로 성격·컨디션·리스크를 잡고, 실제 산책 데이터를 그 개의 입장에서 읽어준다.
  - "여기 지난주에도 왔던 데다" / "오늘 더워서 슬슬 힘들다"
- 게임 요소는 **현실 기반 진행도**만: 동네 구역 탐험, 연속 일수, 새 길 발견.
- 레벨·스탯·전투 없음.

## 원칙: 판정과 서술의 분리

```
GPS 배치 → [코드] 트리거 판정 · 보상 계산 · 달성 여부 → [LLM] 확정된 사실에 문장만 입힘
```

LLM에게 "미션 깼나?"를 묻지 않는다. 보상 인플레와 환각의 원인.

## 3단 루프

| 시점 | 하는 일 | 비중 |
|---|---|---|
| 출발 전 | 오늘 목표 제시. 날씨·미세먼지·기온, 어제 산책량, 견종/나이 반영 | 높음 |
| 이동 중 | 트리거 시 짧은 알림. **빈도 상한 필수** — 산책의 주인공은 개, 폰이 아니다 | 최소 |
| 종료 후 | 경로를 에피소드로 요약. 여기서만 길게 써도 됨 | 높음 |

## 밸런스는 거꾸로다

더 걷게 만드는 게 목표가 아닌 경우가 있다: 노견, 단두종(여름), 관절 이슈, 폭염/한파.

- 보상은 거리 비례가 아니라 **권장량 대비 적정 구간에서 최대**
- 초과하면 보상이 줄고 에이전트가 말린다
- 케어 서비스로서의 정체성이 여기서 나온다

## 병원/약국과 산책이 한 레포인 이유

- **평시**: 산책 반경 안 동물병원을 지도 랜드마크로 노출 → 놀면서 동네 병원 위치가 학습됨
- **유사시**: 산책 중 이상 상황이면 게임을 벗고 병원 모드로 전환 (영업중 + 야간응급 우선)
- 반경 검색 · 좌표 인덱싱 · 영업시간 판정 = **공통 지오 인프라**. 따로 만들면 두 배.
