# OSM 산책 후보 도로망에 잠재 미시 행동을 심는다 — 대조군 셋

2026-08-27 합성, 2026-08-28 리뷰 반영해 다시 돌림. 재현:

```bash
uv run python -m scripts.spikes.territory_paint.latent_dwell_year \
    --cache osm.json --json latent.json
uv run python -m scripts.spikes.territory_paint.latent_readout --json latent.json
```

코드는 `scripts/spikes/territory_paint/latent_dwell_year.py`(합성)와 `latent_readout.py`(읽기),
갈래는 [repeated-dwell-area](../explorations/walk/repeated-dwell-area.md).

## 심는 것은 좌표와 행동이지 답이 아니다

이전 실험이 여기서 미끄러졌다. "도곡공원에 편향을 심고 도곡공원이라는 답을 받기" 는 발견이
아니라 순환이다 — 영역 이름을 우리가 정해 놓고 그 이름을 돌려받았으니까.

    심는 것    이 좌표에서 재방문 확률 p 로 체류 시간 D 를 쓴다
    안 심는 것 그 결과로 field 가 어떤 모양이 될지, 어느 영역으로 묶일지

field 모양은 **우리도 모른다.** 붓·격자·지터·경로 반복이 함께 만든다.

## 도로망의 출처

**"실제 보행 도로망" 이 아니라 "OSM 에서 뽑은 산책 후보 도로망" 이다.** 실제로 사람이 걷는
길인지는 확인 안 했고, OSM 의 `highway` 태그가 그 열한 종류 중 하나인 way 를 전부 담았을
뿐이다. 인도가 태그로 안 들어간 구간은 빠지고, 안 걷는 골목도 들어온다.

    provider    OpenStreetMap / Overpass API
    bbox        37.4855, 127.0480 – 37.4955, 127.0620  (대치·도곡동 약 1.1 × 1.2km)
    highway     footway path pedestrian living_street residential
                service track steps cycleway unclassified tertiary
    fetched_at  2026-08-28T03:19:40Z
    digest      sha256:bae81bdd6474a416  (way 163)

질의 전문과 이 값들은 만들어진 자료의 `source` 키에 그대로 들어간다. **OSM 은 계속 바뀌므로
같은 상자라도 다른 날 뽑으면 다른 그래프가 나온다** — `digest` 가 다르면 그 아래 결과는 서로
비교할 수 없다.

## 무엇을 심었나

노드 1,018 · 최대 연결요소 361 · 교차로 60. 코호트마다 집을 하나씩 골라 60 회 산책을 만들고
멈춤을 심는다.

| | 무엇 | 지날 때 멈출 확률 | 체류 중앙 |
|---|---|---:|---:|
| A | 반복 체류 — 좌표 고정 | 0.75 | 45초 |
| B | 구조적 정지 — 교차로 | 0.35 | 22초 |
| C | 우발 정지 — 매번 다른 자리 | 산책당 0.30 | 18초 |
| D | 긴 휴식 — 좌표 고정 | 0.12 | 260초 |

체류는 로그정규다 — 짧은 멈춤이 흔하고 긴 멈춤이 드물게 섞인다.

**이름은 관측 가능한 것만이다.** "냄새" 도 "신호등" 도 아니고, B 를 구조적이라 부르는 것은
**위치가 교차로라서**지 원인을 안다는 뜻이 아니다.

### 관측 모델 — 흔든 크기와 보고하는 값은 다르다

    jitter_sigma_m        8m    좌표를 실제로 흔든 크기
    reported_accuracy_m  10m    기기가 보고했다고 치는 값

첫 판은 σ=8m 로 흔들어 놓고 `accuracy_m=5.0` 을 박아 자기모순이었다. 지금 붓이 정확도를 안
쓰니 결과에는 영향이 없었지만, **둘은 같은 개념이 아니므로** 값을 맞추는 게 아니라 따로 적는다.

### 대조군이 셋인 이유 — 둘로 했더니 정의와 어긋났다

첫 판은 `planted(A·B·C·D)` 와 `null(B·C)` 둘이었고 null 을 "거짓 양성의 바닥" 이라 불렀다.
**정의와 정면으로 어긋난다** — [정의](../explorations/walk/repeated-dwell-area.md)는 "구조적
정지도 반복 체류에 걸린다, 무엇인지는 M4 가 설명한다" 이므로 B 는 **참 양성**이다. B 가 든
자료를 거짓 양성의 바닥이라 부르면 M3 가 "개 체류냐 구조적 정지냐" 를 갈라야 하고, 그건 M4 의
일을 검출기에 떠넘기는 것이다.

    N0  일반 보행 + C 만     검출기의 **진짜** 거짓 양성 바닥
    S   B + C                B 도 반드시 잡힌다는 검증 = M4 가 필요한 이유
    P   A + B + C + D        회수율

### 정답지는 둘이다 — 잠재 원인과 실제 사건

`truth_only.spots` 는 **어디에 무엇을 심었나**, `truth_only.events` 는 **각 산책에서 실제로
일어난 멈춤**이다. 가르는 이유가 둘.

- **C 는 `spots` 로 못 적는다.** 자리가 매번 다르니 잠재 원인이 없다. `events` 가 없으면
  "검출기가 C 를 안 집었나" 를 확인할 방법이 아예 없었다.
- **A·D 도 심은 좌표에서 멈추지 않는다.** 경로가 발화 반경(12m)에 **처음 들어온** 지점에서
  멈추므로 진행 방향에 따라 좌표가 어긋난다. 그래서 사건마다 `latent_at`(심은 자리)과
  `actual_stop_at`(실제 멈춘 자리)을 같이 남긴다. 안 그러면 검출기가 얼룩 중심을 제대로 찾고도
  `spot.at` 기준으로 오차를 먹는다 — **검출기가 틀린 게 아니라 채점자가 틀린 것이다.**

D2 가 51 번 지나 4 번 멈추고 중앙 292 초 — **드물지만 길다**는 설계가 그대로 나왔다.

**코호트마다 집이 다르다.** 이건 통제된 게 아니라 통제 안 된 것이다 — 아래 결과에서 코호트
차이와 집 차이가 섞여 있고, 그래서 여기 숫자로 문턱을 못 정한다(§M3 요구).

## 심으면서 고친 것 둘

### 자리를 통행 빈도로 골라야 한다

처음엔 무작위 경로의 40~80% 지점에서 골랐다. 그랬더니 긴 휴식 자리가 60 회 중 **5 회만
지나가서 한 번도 안 터졌다**(0/5). 드물게 지나는 가지에 떨어지면 심어도 없는 것과 같다.

**희소성은 `chance` 가 만들어야지 경로 추첨이 만들면 안 된다.** 노드별 통행 수를 세어
35% 이상 지나는 자리에서 고르도록 바꿨다. 집 근처 150m 는 뺀다 — 모든 산책이 지나므로
거기 심으면 "반복 체류" 와 "늘 지나는 길" 이 애초에 안 갈린다.

### 자리끼리 겹치면 정답지가 자기를 헷갈린다

A·D 끼리는 60m 를 띄웠는데 **B 와의 거리를 안 봤다.** 그래서 A1 과 B2 가 한 자리에
떨어졌고 읽기 값이 소수점까지 같았다 — 둘 다 대비 22.29x · 갔을때체류 286.7.

그러면 검출기가 무엇을 찾았는지 **우리도 못 가린다.** 합성 자료의 값어치는 "무엇이 참인지
우리가 안다" 는 것뿐이라, 그 앎이 흐려지면 실험 전체가 못 쓰게 된다. 회귀 테스트로 고정했다.

## 정답을 알고 읽어 봤다 — 그리고 읽기 장치가 졌다

[M1 의 읽기 장치](2026-08-27-mass-conserving-kernel.md)로 정답 자리를 읽고, **같은 장치를
field 전체에 훑어** 그 분포와 견줬다. 격자 8 단위(칸 반지름 6.3m · 중심 간격 11.0m), 읽기
반경 25m, 붓 `계단 3·8·20`, 60 장 전부.

### 1. **아무것도 안 심은 N0 의 최고봉이 심은 자리 전부를 이긴다**

이게 이번 측정의 결과다. N0 은 A 도 B 도 D 도 없이 일반 보행 + 우발 정지 21 번뿐인데,
그 field 최고봉이 **31.5x** 로 P 의 어떤 정답 자리(최고 14.3x)보다도 높다. 그 자리는 집에서
94~236m 떨어진 **통행이 몰리는 길목**이고, 거기서 멈춘 개는 없다.

세 축 어느 것으로도 안 갈린다. 등장 96.7%, 갔을때 199.8 — A0 의 85.0% · 155.7 보다 **둘 다
높다.** "통과는 퍼지고 체류는 뭉친다" 를 기대하고 집중도(최고칸 ÷ 원반합)를 재 봤지만
8~13% 로 사실상 평평하다.

읽기 반경을 12~18m 로 줄여도(중심 간격 11m 라 그 아래는 격자가 거절한다) 뒤집히지 않고,
붓 도달거리를 20m → 8m → 6m 로 줄이면 집중도 차이가 3.1%p → 4.8%p 로 조금 벌어질 뿐
대비 순위는 그대로다 — N0 최고봉 15.4x 대 P 의 A·D 최고 7.1x.

**왜 지는지는 정의에 이미 있다.** `대비 = 기대체류/기준선` 이고 `기대체류 = 등장률 ×
갔을때체류` 다. 길목은 등장률이 1.0 이고, occupancy 가 [질량 보존을 안 하므로](2026-08-27-mass-conserving-kernel.md)
지나가기만 해도 원반에 상당한 질량이 쌓인다. **대비는 통행과 체류의 곱이라 통행만으로도 커진다.**

그래서 M3 는 대비를 문턱으로 쓰면 안 된다. 필요한 것은 **통행 수에 불변인 축** — 지나감이
남기는 질량을 빼고 남는 몫이다. 그리고 **그 지나감의 몫을 재는 것이 바로 N0 의 쓸모다.**
N0 은 "대비의 거짓 양성 바닥" 이 아니라 **통행 항의 눈금**이다.

### 2. 기준선이 사람마다 다르다 — 대비는 사람 간 비교 불가

기준선이 N0 6.1 · P 13.7 · S 18.4 로 **3 배** 벌어진다. 체류를 많이 심을수록 칠해진 칸의
전형값이 올라가서 **기준선이 체류에 따라 같이 움직인다.** 그래서 같은 종류의 B 정지가
S 에서 6.3~11.2x, P 에서 4.7~14.3x 로 읽힌다.

**M3 의 문턱을 어느 한 코호트의 읽기에서 뽑으면 안 된다.** 게다가 여기서는 코호트마다 집이
달라 경로 구조 차이까지 섞여 있다.

### 3. 대비만으로는 A 와 B 가 안 갈린다

P 에서 A 는 6.9~9.7x, B 는 4.7~14.3x 로 **완전히 겹친다.** 구조적 정지도 매 산책 같은
자리에서 반복되니 당연한 결과다.

이건 실패가 아니라 **정의가 그렇게 되어 있다** — 행동 분류기로 거르지 않고 지도 맥락으로
설명한다는 것이 M4 의 계획이고, S 코호트가 그 필요를 숫자로 보여준다. M3 는 "A 를 찾았다" 를
주장할 때 B 를 같이 찾았다는 사실을 반드시 같이 내야 한다.

## 이 합성이 답하지 않는 것

- **검출.** 여기는 자료만 만든다. 정답 자리를 **알고** 읽은 위 표는 검출이 아니다 —
  자리를 모르는 채로 field 에서 찾아내는 것이 M3 다.
- **문턱.** 위 이유로 여기서 못 정한다. 집 하나 × 씨앗 하나짜리 한 뽑기다.
- **격자·붓.** 8 단위 · `계단 3·8·20` 으로 읽어 봤을 뿐 고른 것이 아니다.
- **실기기 정지 분포.** 확률과 체류 중앙값은 전부 가정이다. dwell 문서 §22 의 1 번 측정
  ("실제 정지 분포")이 아직 안 됐고, 그게 되면 이 숫자들을 갈아야 한다.
- **C 의 회수 가능성.** 우발 정지는 매번 다른 자리라 반복이 없다 — 이제 `events` 에 남으니
  M3 가 "안 집었나" 를 확인할 수는 있다.
