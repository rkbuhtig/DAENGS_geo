# 실제 도로망에 잠재 미시 행동을 심는다 — 대조군 포함

2026-08-27 합성. 재현:

```bash
uv run python -m scripts.spikes.territory_paint.latent_dwell_year \
    --cache osm.json --json latent.json
```

코드는 `scripts/spikes/territory_paint/latent_dwell_year.py`,
갈래는 [repeated-dwell-area](../explorations/walk/repeated-dwell-area.md).

## 심는 것은 좌표와 행동이지 답이 아니다

이전 실험이 여기서 미끄러졌다. "도곡공원에 편향을 심고 도곡공원이라는 답을 받기" 는 발견이
아니라 순환이다 — 영역 이름을 우리가 정해 놓고 그 이름을 돌려받았으니까.

    심는 것    이 좌표에서 재방문 확률 p 로 체류 시간 D 를 쓴다
    안 심는 것 그 결과로 field 가 어떤 모양이 될지, 어느 영역으로 묶일지

field 모양은 **우리도 모른다.** 붓·격자·지터·경로 반복이 함께 만든다.

## 무엇을 심었나

실제 OSM 보행 도로망(대치·도곡동, 노드 1,018 · 최대 연결요소 361 · 교차로 60) 위에서
집 하나를 골라 60 회 산책을 만들고, 거기에 멈춤 네 종류를 심는다.

| | 무엇 | 지날 때 멈출 확률 | 체류 중앙 |
|---|---|---:|---:|
| A | 반복 체류 — 좌표 고정 | 0.75 | 45초 |
| B | 구조적 정지 — 교차로 | 0.35 | 22초 |
| C | 우발 정지 — 매번 다른 자리 | 산책당 0.30 | 18초 |
| D | 긴 휴식 — 좌표 고정 | 0.12 | 260초 |

체류는 로그정규다 — 짧은 멈춤이 흔하고 긴 멈춤이 드물게 섞인다. GPS 지터 σ=8m.

**이름은 관측 가능한 것만이다.** "냄새" 도 "신호등" 도 아니고, B 를 구조적이라 부르는 것은
**위치가 교차로라서**지 원인을 안다는 뜻이 아니다.

### 대조군이 문턱의 출처다

    planted (P)   A · B · C · D 를 다 심는다
    null    (N)   **A 와 D 를 안 심는다.** B · C 만

검출기가 N 에서 찾아내는 것이 **거짓 양성의 바닥**이다. B 를 두 쪽에 다 심는 이유는,
구조적 정지가 어차피 반복 체류로 잡히므로 대조군에도 있어야 "A 를 찾았다" 가 "B 를 찾았다"
와 갈리기 때문이다.

## 만들어진 자료

| | 산책 | fix | 심은 자리 (멈춤/지남 · 체류 중앙) |
|---|---:|---:|---|
| P | 60 | 86,405 | A0 32/46·45s · A1 42/58·47s · **D2 9/46·288s** · B0 21/60·21s · B1 20/59·26s · B2 8/31·22s |
| N | 60 | 79,376 | B0 31/60·22s · B1 24/60·22s · B2 24/60·19s |

D2 가 46 번 지나 9 번 멈추고 중앙 288 초 — **드물지만 길다**는 설계가 그대로 나왔다.

## 심으면서 고친 것 둘

### 자리를 통행 빈도로 골라야 한다

처음엔 무작위 경로의 40~80% 지점에서 골랐다. 그랬더니 긴 휴식 자리가 60 회 중 **5 회만
지나가서 한 번도 안 터졌다**(0/5). 드물게 지나는 가지에 떨어지면 심어도 없는 것과 같다.

**희소성은 `chance` 가 만들어야지 경로 추첨이 만들면 안 된다.** 노드별 통행 수를 세어
35% 이상 지나는 자리에서 고르도록 바꿨다. 집 근처 150m 는 뺀다 — 모든 산책이 지나므로
거기 심으면 "반복 체류" 와 "늘 지나는 길" 이 애초에 안 갈린다.

### 자리끼리 겹치면 정답지가 자기를 헷갈린다

A·D 끼리는 60m 를 띄웠는데 **B 와의 거리를 안 봤다.** 그래서 A1 과 B2 가 한 자리에
떨어졌고 읽기 값이 소수점까지 같았다 — 둘 다 대비 22.29x · 갔을때체류 286.7.

그러면 검출기가 무엇을 찾았는지 **우리도 못 가린다.** 합성 자료의 값어치는 "무엇이 참인지
우리가 안다" 는 것뿐이라, 그 앎이 흐려지면 실험 전체가 못 쓰게 된다. 회귀 테스트로 고정했다.

## 벌써 드러난 것 둘 — M3 가 알아야 한다

정답 자리를 [M1 의 읽기 장치](2026-08-27-mass-conserving-kernel.md)로 읽어 봤다
(격자 8 단위, 읽기 반경 25m, 60 장 전부).

| | 대비 | 등장 | 갔을 때 체류 |
|---|---:|---:|---:|
| **P** (기준선 6.2) | | | |
| A0 | 34.6x | 76.7% | 280 |
| A1 | 41.9x | 96.7% | 270 |
| D2 | 38.1x | 76.7% | 309 |
| B0 | 20.9x | 100.0% | 130 |
| B1 | **31.2x** | 98.3% | 197 |
| B2 | 16.6x | 51.7% | 200 |
| **N** (기준선 18.4) | | | |
| B0 | 6.3x | 100.0% | 116 |
| B1 | 10.7x | 100.0% | 197 |
| B2 | 11.2x | 100.0% | 206 |

### 1. 대비만으로는 A 와 B 가 안 갈린다

P 에서 A 는 34.6~41.9x, B 는 16.6~31.2x 로 **겹친다.** B1 의 31.2x 가 A0 의 34.6x 와
거의 같다. 구조적 정지도 매 산책 같은 자리에서 반복되니 당연한 결과다.

이건 실패가 아니라 **설계가 예상한 것**이다 — 행동 분류기로 거르지 않고 지도 맥락으로
설명한다는 것이 M4 의 계획이고, 이 표가 그 필요를 숫자로 보여준다. 다만 M3 는 "A 를
찾았다" 를 주장할 때 B 를 같이 찾았다는 사실을 반드시 같이 내야 한다.

### 2. 기준선이 사람마다 다르다 — 대비는 사람 간 비교 불가

P 의 기준선이 6.2, N 이 18.4 로 **3 배 차이**다. 그래서 같은 종류의 B 정지가 P 에서
16.6~31.2x, N 에서 6.3~11.2x 로 읽힌다. 정지가 달라서가 아니라 **경로 구조가 달라서**다.

**M3 의 문턱을 N 의 자리 읽기에서 뽑으면 안 된다.** 그건 N 의 기준선에 묶인 값이라
P 에 그대로 못 쓴다. 문턱은 **각 사람의 field 를 훑어 얻은 대비 분포**에서 나와야 하고,
N 이 주는 것은 "패턴을 안 심었을 때 그 분포의 위쪽 꼬리가 어디까지 가나" 다.

## 이 합성이 답하지 않는 것

- **검출.** 여기는 자료만 만든다. 정답 자리를 **알고** 읽은 위 표는 검출이 아니다 —
  자리를 모르는 채로 field 에서 찾아내는 것이 M3 다.
- **문턱.** 위 이유로 여기서 못 정한다.
- **격자·붓.** 8 단위 · `계단 3·8·20` 으로 읽어 봤을 뿐 고른 것이 아니다.
- **실기기 정지 분포.** 확률과 체류 중앙값은 전부 가정이다. dwell 문서 §22 의 1 번 측정
  ("실제 정지 분포")이 아직 안 됐고, 그게 되면 이 숫자들을 갈아야 한다.
- **C 의 회수 가능성.** 우발 정지는 매번 다른 자리라 반복이 없다 — 검출기가 이걸 안
  집는지도 M3 가 봐야 한다.
