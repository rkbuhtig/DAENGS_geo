# 계절·강수 산책 묶음 — 선택 규칙 첫 실험

> 이 문서는 Geo `185747f` 기반 로컬 실험의 당시 기록이다. 본문의 코드 경로·실행 명령·localhost 주소는 해당 실험 작업 공간을 가리킨다. 이 문서 PR에는 실험 실행 코드와 원천 캐시를 포함하지 않는다. [종합 보고서](2026-09-07-walk-diary-experiment-report.md)에서 최신 검토 결론과 이전 정책을 대체한 단계를, [보존 자료 안내](2026-09-07-walk-diary-evidence/README.md)에서 저장소만으로 확인할 수 있는 범위를 확인한다.

상태: 실험. 기준 Geo `185747f`, 로컬 브랜치 `experiment/walk-cohort-season-weather`.
제품 이식 결정은 하지 않았다. 지역은 사용자 요청에 따라 범위 밖이다.

## 목적과 실행

계절·강수 조건으로 선택한 산책 묶음이 셀로판 분모와 시간순 장면 소속에 동일하게 반영되는지
확인한다. 당시 로컬 `scripts/spikes/walk_cohort/README.md`의 실행 방법.

합성 입력 13회(그중 다른 강아지 1회, 알려진 빈 입력 1회)를 기존
`compute_facts → paint_sheet → spatial_field`에 넣었다. 장면·날씨는 수기 fixture다.
태그만 화면에서 거르는 시안과 달리 실제 Geo 공간 계산을 사용하지만, 실제 사용자 기록이나
실제 날씨를 수집한 결과는 아니다. LLM·운영 API·DB는 호출하지 않았다.

이번 워크스페이스 실행은 기존 Python 3.12.13 환경을 재사용했다. 새 의존성은 없다.

```powershell
python -m pytest tests/spikes/test_walk_cohort.py -q
python -m ruff check scripts/spikes/walk_cohort tests/spikes/test_walk_cohort.py
python -m scripts.spikes.walk_cohort --out ../experiments/walk-cohort-v1
```

결과: 타깃 테스트 **35개 통과**, Ruff 통과, CLI 예상 산책 집합 **12/12 일치**.
전체 테스트는 실행하지 않았다. 런타임 출력은 저장소 밖에 두며 `inventory.json`,
`results.json`, `REPORT.md`로 재생성할 수 있다.

위 수치는 합성 fixture의 집합·계산 결과이며, 제품의 적절한 산책 수나 장면 수가 아니다.

## 확인한 경계

- 축 내 OR·축 간 AND, KST 시작 날짜 기반 계절/기간, 강아지 소유 집합의 분리.
- 자정 이후 장면이어도 세션의 계절은 시작 날짜 기준. 장면은 절대 시각으로 정렬.
- 정보 없음은 dry와 구별한다. 날씨 필터가 없으면 미상도 포함한다.
- 장면 0개가 공간 집계에서 세션을 빼는 이유가 되지 않는다.
- 알려진 빈 장을 더하면 visit_rate 분모가 늘고 값은 낮아지지만 기존 장면은 유지된다.
- 장면 문구·일기 포함 여부를 바꿔도 필드 값과 산책 묶음은 유지된다.
- 중복 세션·세션과 장의 불일치·다른 Paint 세대는 조용히 누락하지 않고 거부한다.

## 발견한 Geo/Dev 차이

Geo의 기존 Context Plane 강수 분류는 강수량 문턱 기반 v1이다. Dev `3c750df`는 관측 종류와
WMO 코드 기반 v2이고 눈·혼합을 구별한다. 이번 실험의 어댑터는 후자에 맞췄으며 Geo 운영
분류를 변경하지 않았다. 강수량만 있는 Geo의 오래된 자료는 이 어댑터에서 unknown으로 남는다.

따라서 이식 전에 기존 기록을 어떻게 읽을지 별도 판단이 필요하다. 강수량을 비라는 관측
종류로 변환하거나 snow/mixed를 rain으로 접어 계약 차이를 숨기지 않는다.
