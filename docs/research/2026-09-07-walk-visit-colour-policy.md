# 방문 비율과 색 — Geo 실험 정책 v1

> 이 문서는 Geo `185747f` 기반 로컬 실험의 당시 기록이다. 본문의 코드 경로·실행 명령·localhost 주소는 해당 실험 작업 공간을 가리킨다. 이 문서 PR에는 실험 실행 코드와 원천 캐시를 포함하지 않는다. [종합 보고서](2026-09-07-walk-diary-experiment-report.md)에서 최신 검토 결론과 이전 정책을 대체한 단계를, [보존 자료 안내](2026-09-07-walk-diary-evidence/README.md)에서 저장소만으로 확인할 수 있는 범위를 확인한다.

이 정책은 관측 기록의 기술 통계다. 익숙함, 새로움, 통계적 유의성, 방문 확률 예측이나
서술을 결정하지 않는다. 운영 이식 전의 명시적 실험 기준이다.

## 산책 선택과 분모

계절·강수로 선택된 모든 산책과 장면은 탐색에 남긴다. 그중 위치 관측 상태가 `complete`로
명시된 산책만 방문 비율 분모 N에 포함한다. `partial`, `missing`, `unknown`은 제외하고 수를
표시한다. 산책 종료나 빈 Cellophane이라는 이유만으로 관측이 완전하다고 추정하지 않는다.

현재 합성 생성기는 연속 경로를 끝까지 생성한 경우 complete, 위치를 만들지 않은 기존
fixture는 missing으로 표시한다. 추가 통계 사례에서는 partial을 명시한다. 실제 로그의
complete 판정/관측 커버리지 기준은 아직 구현하지 않았으므로 실제 데이터로 확대 적용하지 않는다.

complete이면서 확정적으로 빈 장은 분모에 포함한다. 이는 위치 누락과 다른 상태다.
부분 관측에서 확인된 방문만 섞어 넣으면 셀마다 분모 해석이 달라지므로, 이번 버전에서는
산책 전체를 제외한다. 누락이 많은 경우의 선택 편향은 해결하지 않으며 제외 수를 숨기지 않는다.

## 방문 판정

동일한 Geo Paint 세대(8u, NARROW_STEP)의 원본 Cellophane에 양의 관측 질량이 있는 셀을
그 산책에서 관측된 방문 support로 본다. 추가 peak 문턱은 0이다. 셀 크기와 painter의 폭을
포함한 판정이므로 정확한 GPS 중심선 통과 여부가 아니다.

한 산책이 같은 셀을 여러 번 지나거나 오래 머물러도 분자는 1만 증가한다. 셀별 k/N을
저장된 Hex 자료에서 계산한다. N=0은 비율 없음(null)이고 0%로 표시하지 않는다.
N>0, k=0은 계산 대상 기록에서 관측된 방문이 없다는 뜻이며 사용자가 실제로 가지 않았다는
단정이 아니다. 1/1과 100/100은 같은 색이지만 분모를 항상 함께 확인할 수 있다.

## 색과 외곽

0~100%를 고정된 연한 분홍→진한 분홍 RGB 색상에 선형 대응한다. 범례는 0/25/50/75/100%.
조회 집합 최대값, 산책 수, 체류 시간에 맞춰 색상 범위를 다시 늘리지 않는다.

원본 셀 비율을 2m raster로 옮긴다. 비율 표면과 활성 영역 mask를 각각 sigma=5m로
동일하게 평활화한다. 표시 비율은 blur(rate)/blur(mask), 외곽 alpha는 0.72×blur(mask)다.
색을 정하는 값과 외곽 투명도를 분리한다. 일정한 비율의 영역은 번짐 후에도 같은 RGB를 갖는다.
서로 다른 셀 사이에서는 주변 비율이 보간되므로 지도 색이 클릭한 셀의 정확한 숫자와 같다고
주장하지 않는다. 밝은 지도/외곽 alpha에 따른 최종 화면 밝기도 범례와 완전히 같지는 않다.

지도를 누르면 서버의 동일한 Hex 색인으로 원본 k/N을 보여준다. 표시용 번짐 영역에만 속하면
0/N일 수 있다. N=0이면 계산할 수 없음으로 표시한다. 표시 raster를 방문 판정에 되먹이지 않는다.

기존 시간 밀도 브러시는 비교용으로 보존하며 방문율 범례를 적용하지 않는다.

## 구현과 검산 결과

`visit_statistics.py`에서 분모·분자, 표시 보간, 원본 위치 조회를 분리했다. 기존 `field`와
`display`는 앞선 실험 재현용으로 유지하고, 새 `statistics`를 기본 화면의 출처로 사용한다.
UI에서 방문 비율/기존 밀도 표현을 전환한다. 원본 위치 조회는 `/walk-cohort-lab/inspect`가
공유 Hex 색인을 사용하며, 조회 중 필터가 바뀌면 이전 위치 응답은 표시하지 않는다.

통계 검산 선택 메뉴:

- `ratio3`: 반복 2회 + 우회 1회, 특정 구간 2/3.
- `ratio30`: 동일 경로 구성 10배, 같은 구간 20/30.
- `long`: ratio3 중 첫 산책에서 정지 관측 30개(5분)를 추가.
- `missing`: ratio3에 위치 없는 산책 1회와 partial로 표시한 산책 1회 추가.

실행한 관련 검사:

```text
pytest tests/spikes/test_walk_visit_statistics.py tests/spikes/test_walk_cohort_lab.py -q
19 passed, 1 existing Starlette/httpx deprecation warning (18.79s)
ruff check scripts/spikes/walk_cohort/lab.py scripts/spikes/walk_cohort/visit_statistics.py tests/spikes/test_walk_visit_statistics.py
All checks passed
```

Windows Edge headless에서 지도 위 원본 셀 (832462,376297)을 실제 클릭했다.
3회에서는 2/3=66.7%, 30회에서는 20/30=66.7%, missing에서는 선택 5회·계산 3회 중
2회=66.7%로 표시됐다. ratio3/ratio30/long/missing의 방문 비율 PNG가 정확히 같았다.
표시용 번짐에만 속한 위치는 원본 0/3을 반환했으며, N=0은 계산할 수 없음으로 표시됐다.
누락 기록의 장면은 목록에 남았고 이전 시간 밀도 표현은 별도 범례로 전환됐다.

320/360/430/760/1120px 가로 넘침 없음, 폰에서 지도와 선택 카드 동시 노출, JS 예외 없음도
확인했다. 범례는 지도 중심부와 같은 최대 alpha를 사용한다. 지도 배경과 외곽에서는 실제
픽셀 밝기가 달라지므로 정확한 값은 원본 위치 조회로 확인한다.

실행 URL: `http://127.0.0.1:8766/walk-cohort-lab?population=ratio3`.
검산은 합성 자료에 한정된다. 실제 로그의 완전성 판정, 표본 선택 편향 보정, Android 기기 성능,
Dev·App 이식이나 전체 스위트 검증은 수행하지 않았다.
