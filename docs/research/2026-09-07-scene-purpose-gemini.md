## 이번 정책

- 행동 장면: 사용자가 직접 남긴 행동이 중심이다. 기존 냄새·사진 핀을 별도 시점으로 유지하며 필수 보존한다.
- 공간 전환: 공원·하천을 포함한 배경 전환, 상가가 모인 구간으로 들어오거나 빠져나가는 전환, 가까운 대상의 접근·멀어짐·지나침을 남길 후보로 삼는다.
- 연결 구간: 위 사건이 없는 부분. 지도 동선으로 유지하고 카드 선택은 금지한다. 시작·종료도 세션의 틀로 제공하며 카드 수를 채우는 도입·마무리를 강제하지 않는다.

사건을 최대 5분으로 자르던 규칙을 해제했다. 배경 변화·행동 핀·GPS 단절에 따른 분리는 유지한다. 이동만 계속되는 완전 합성 12분 통제 입력이 하나의 연결 구간으로 남고, 장면 0개를 정상으로 처리하는 것을 오프라인 테스트로 확인했다. 이 통제 입력을 Gemini에 호출한 것은 아니다.

거리 관계와 배경 임계값은 v2의 실험값을 유지한다. 실제 GPS/지역별 밀도에 맞춘 검증은 아직 없다. 의미 없는 작은 상가 변화(적음↔산재)와 행정동 변화만으로는 장면 후보를 만들지 않는다.

각 후보에는 역할, 카드 자격, 보존 필요 여부, 남길 이유, 중심 근거 ID를 붙였다. 중심 선정 우선순위는 사용자 행동 → 접근 후 멀어짐 → 배경 전환 → 접근/멀어짐이다. 거리 관계는 최소 관측 거리가 100m 이내일 때 후보 중심으로 사용할 수 있게 했다.

행정동 이름은 로컬 지도/감사 자료에 남기고 모델의 경쟁 주제에서 제거했다. 모델에는 해당 사건의 중심 근거와 배경만 제공한다. 선택된 전환 장면은 중심 근거를 인용해야 한다. 장면당 행동 근거 1개, 장소 근거 최대 2개, 참가자 최대 2명이다. 임의 사건 병합은 허용하지 않는다.

모델은 0~7개를 선택하며 미선택 후보 전부에 생략 이유를 반환한다. 연결 구간이 카드로 들어왔는지, 필수 행동을 놓쳤는지, 중심 근거를 뺐는지, 미선택 목록이 정확한지 검사한다. 글이 실제로 변화의 의미를 보존했는지는 별도 검토다.

## 실제 실행 결과

`gemini-3.1-flash-lite`, temperature 0.2. 생성 3회, 재시도 없음. 실제 공공 공간 캐시 + 동일한 합성 산책이며 참가자/행동 핀은 가상이다. 입력과 프롬프트를 함께 바꾼 탐색 실험으로, 정책 하나의 인과 효과를 분리한 비교는 아니다.

| 조건 | 후보: 행동 / 전환 / 연결 | 선택 장면 | 선택: 행동 / 전환 | 입력 토큰 | 전체 토큰 | 시간 |
| --- | --- | ---: | --- | ---: | ---: | ---: |
| 이동만 | 0 / 7 / 4 | 7 | 0 / 7 | 3,283 | 4,637 | 7.359초 |
| 행동 핀 추가 | 2 / 7 / 6 | 5 | 2 / 3 | 3,868 | 5,099 | 6.344초 |
| 행동 핀 + GPS 단절 | 2 / 8 / 8 | 7 | 2 / 5 | 4,355 | 5,895 | 7.000초 |

입력 총 11,506토큰(v2 성공 3건 13,082 대비 약 12% 감소), 전체 15,631토큰, 호출 지연 합계 20.703초. 구조 검사 3건 모두 통과했다. 연결 후보 총 18개는 모두 카드에서 제외됐다. 선택된 15개 전환 장면은 모두 시스템이 지정한 중심 근거를 인용했다.

연결 제외, 행동 보존, 중심 근거 인용은 시스템 규칙을 따른 결과다. 모델의 독립적 중요도 판단이 좋아졌다는 지표로 해석하지 않는다. 조건별 1회 출력으로 일반 품질 성공률도 산출하지 않는다.

## 내용 검토

이전의 행정동 이동 문장 대신 ‘상가 구간을 지나 늘벗근린공원 가까이로 이동’, ‘공원 가까이에서 하천 가까이로 주변 환경이 바뀜’처럼 전환이 본문에 나타났다. 지도에 동선을 유지하면서 시작·마무리 카드는 빠졌다. 사진은 15분 시점에 남았다.

동시에 다음 문제가 나왔다.

1. **반복 제거 부족:** 이동만 조건은 전환 후보 7개를 전부 선택했다. 비슷한 ‘이동했다’ 문장이 이어지고, 상가 적음/많음 변화를 모두 독립 카드로 볼 가치가 있는지는 아직 검증되지 않았다.
2. **앞부분 편중:** 행동 핀 조건은 7개까지 허용했는데 5개를 생성하고, 후반 전환 4개를 모두 ‘장면 수 제한’ 때문에 생략했다고 설명했다. 마지막 선택 사건은 17~20분이며, 이후 18분 49초의 후보 선택 이유가 충분하지 않다. 후반을 반드시 채우라는 의미는 아니며 생략 설명의 일관성이 문제다.
3. **중심 근거의 의미 축소:** 이동만 조건은 ‘거리가 줄었다 다시 늘어남’을 인용했지만 ‘하천과의 거리가 변화했다’로 적어 방향과 순서를 지웠다. ID 검사만으로 정보 손실을 잡을 수 없다.
4. **근거 없는 행동 재발:** 단절 조건은 ‘멈춰 냄새를 맡았다’고 썼다. 입력에는 냄새 맡기만 있다. 사진 제목에 ‘기념’ 목적도 붙을 수 있었다.
5. **동일 공간 유형과 동일 장소 혼동:** 상가 구간을 다시 만난 것을 ‘복귀’로 표현했다. 같은 장소로 되돌아왔다는 근거는 없다.
6. **잘못된 자기 설명:** 단절 조건의 limitations는 누락 구간을 이동 경로로만 처리했다고 썼다. 실제 시스템은 누락을 연결하지 않으며 지도에서도 끊겨 있다.

따라서 이번 결과는 역할/중심 근거 정책이 문장의 초점을 바꾸는 데 도움이 된 사례이며, 선정 품질·서술 사실성이 완성됐다는 결과는 아니다. 다음 실험에서는 중복 전환 묶음, 전반·중반·후반을 함께 본 상대적 선택 이유, 서술의 근거 보존 여부를 다루는 것이 적절하다. 시간대를 할당해 카드 수를 강제하는 정책으로 곧바로 바꾸지는 않는다.

## 산출물과 검증

코드: `scripts/spikes/storyboard_composer/selection.py`, `selection_run.py`, `selection-audit.js`, `test_selection.py`. 공용 추출기에 선택적인 시간 제한 인자를 추가하되 기본 300초는 유지하여 이전 v2 계약을 바꾸지 않았다. 공용 exporter는 v2를 비교 기준으로 읽을 수 있고, 모델에 전송하지 않은 로컬 행정동 조각을 입력 보관함에 표시하지 않는다.

실제 결과: 작업 공간 `outputs/storyboard-composer/gemini-03/`. 조건별 input/audit/request/response/receipt, 전체 runs, 해시에 연결한 reviews, 브라우저 comparison/HTML/JS. 생성 제목·본문·요약·선정 및 생략 이유를 원문 그대로 보존했다. 이전 산출물은 다시 생성하지 않았다. 키는 환경 변수와 HTTPS 헤더로만 사용했다.

```powershell
& ../DAENGS_geo/.venv/Scripts/python.exe -m scripts.spikes.storyboard_composer.selection_run --materials ../../outputs/storyboard-composer/materials.json --out ../../outputs/storyboard-composer/gemini-03 --run
& ../DAENGS_geo/.venv/Scripts/python.exe -m scripts.spikes.storyboard_composer.episode_export ../../outputs/storyboard-composer/gemini-03 ../../outputs/storyboard-composer/gemini-02
& ../DAENGS_geo/.venv/Scripts/python.exe -m unittest scripts.spikes.storyboard_composer.test_selection scripts.spikes.storyboard_composer.test_episodes scripts.spikes.storyboard_composer.test_contract -v
```

표적 회귀 검사 23개 통과. 새 사례는 12분 연결 구간 유지, 0개 장면 허용, 연결 카드 거부, 행동 보존, 행정동 정보의 모델 입력 제외, 생략 목록 완전성, 중심 근거 누락 거부를 포함한다. 브라우저에서 후보 역할·생략 이유와 지도 핀→사진 장면 연결을 확인했다. 앱·서버 운영 코드를 변경하거나 실제 사용자 산책을 전송하지 않았다.
