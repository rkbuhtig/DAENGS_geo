# 겹 수와 비율을 함께 보는 농도 실험

> 이 문서는 Geo `185747f` 기반 로컬 실험의 당시 기록이다. 본문의 코드 경로·실행 명령·localhost 주소는 해당 실험 작업 공간을 가리킨다. 이 문서 PR에는 실험 실행 코드와 원천 캐시를 포함하지 않는다. [종합 보고서](2026-09-07-walk-diary-experiment-report.md)에서 최신 검토 결론과 이전 정책을 대체한 단계를, [보존 자료 안내](2026-09-07-walk-diary-evidence/README.md)에서 저장소만으로 확인할 수 있는 범위를 확인한다.

## 목적과 범위

겹 수가 늘수록 진해지는 기존 표현에, 선택한 산책 중 차지하는 비율을 제한적으로 반영한다.
Geo 실험 UI에 `겹 수만 / 비율 30% 반영 / 비율 50% 반영`을 제공하며 기본값은 30%다.
기존 비율 전용 표현도 비교용으로 유지한다. Dev·App, 서술 정책, 익숙함 판정은 변경하지 않는다.

## 표시식

```text
k = 해당 픽셀의 산책별 표시 마스크 가중치를 합한 값
N = 위치 관측이 완전하다고 명시된 산책 수
p = clamp(k / N, 0, 1)
base = 0.72 × log(1 + min(k, 100)) / log(101)
alpha = base × (1 - λ + λ × p)
λ ∈ {0, 0.3, 0.5}; N = 0이면 alpha = 0
```

30%와 50%는 방문율 임계값이나 통계적 신뢰도가 아니라 보정 강도다.
30% 모형의 배율은 0.7~1, 50% 모형은 0.5~1이다. 로그 곡선과 100겹 상한도
기존 시각 실험의 임시 값이며, 데이터로 최적화하거나 통계적으로 추정한 계수가 아니다.

- 1/1의 중심 농도는 세 모형 모두 약 0.108로 연하다.
- 같은 20겹이면 20/20이 20/100보다 진하다(혼합 모형).
- 같은 2/3 비율이면 20/30이 2/3보다 진하다.
- 조건을 바꾸어 N이 달라지면 같은 k의 농도도 바뀐다. 범례에 현재 N과 비율을 함께 쓴다.
- 서로 다른 N끼리 비교하면 더 적은 겹 수가 더 진할 수도 있다. 전체 집합 간 겹 수 순위를
  항상 보존하는 모형은 아니다. 정확한 절대 횟수 비교에는 `겹 수만` 모형을 사용한다.
- 100겹 이후에는 바탕 농도만 상한에 도달하며, 혼합 모형의 비율 보정은 계속 적용된다.

## 브러시와 원본 통계

기존 2m inset, sigma 5m, 외곽 smoothstep 마스크를 그대로 사용한다. 세 모형의 픽셀 좌표,
경계, 색상은 같고 alpha만 달라진다. alpha가 줄면 눈에 보이는 폭은 조금 줄어 보일 수 있다.
가장자리 k와 p는 부드러운 표시용 보간 값이다. 같은 경로를 모두 걸었어도 외곽 p는 1보다
작아지므로 외곽은 추가로 연해진다. 이것을 원본 방문 비율이라고 표시하지 않는다.

지도 클릭 정보는 기존 원본 Hex의 정수 k/N이다. 마스크를 Hex 판정에 되먹이지 않는다.
누락·부분 관측은 N에서 제외한다. 한 산책에서 더 머무른 시간은 겹 수를 늘리지 않는다.
표시 모형 전환은 서버 재조회 없이 이루어지고 선택한 장면·경로·지도 위치를 유지한다.

## 재현

`/walk-cohort-lab?population=ratio30&model=hybrid30`에서 세 버튼을 전환한다.
`model=count|hybrid30|hybrid50|rate`로 직접 열 수 있다.
검산 메뉴의 `single`, `ratio3`, `ratio30`, `long`, `missing`은 기존 합성 입력을 사용한다.

## 검증 결과

작업 공간 루트에서 Node로 `work/check-hybrid-brush.cjs`를 실행해 통과했다.
이번 변경은 HTML/JS 표시와 문서에 한정되어 Python 전체 또는 패키지 테스트를 반복하지 않았다.

장면 선택 시 배경 유지, 원본 2/3 조회, URL 모형 복원, 빈 집합 처리를 확인했다.
320/360/430/760/1120px에서 가로 넘침이 없고 390px에서 지도와 선택 카드가 함께 보인다.
JS 오류는 없었다. 30% 데스크톱·모바일 스크린샷을 직접 확인했다.
