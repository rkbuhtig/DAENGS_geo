## 이 레포에서 정할 것
- [ ] 병원 **영업시간 데이터 출처** (공공데이터에 없음. 최대 작업량)
- [ ] 위치 배치 업로드 주기 (앱 팀과 합의, 배터리 vs 반응성)
- [ ] 이동 중 알림 빈도 상한 값 (세션당 N회, 간격 M분)
- [ ] 위치 프라이버시 정책 (시작/종료 좌표 절삭, 보관 기간)
- [ ] 어뷰징 검증 임계값 (속도/가속도)
- [ ] 프로필 함수 구체값: 나이·체중·brachy·flags·기온 → 권장 시간/거리
- [ ] 지도 제공사 확정 (팀 클라이언트 SDK 결정 따름) — `07-map-provider.md`
- [ ] 딥링크 스킴 이름 (`daengs://` 가안)

## 조사 완료 (2026-08-19) — 리뷰/평가 데이터 출처
- 국내 동물병원 리뷰 API: **없음.** 네이버/카카오 로컬 API는 이름·주소·전화·카테고리·상세페이지 링크만. 펫닥·핏펫 등 공개 API 없음
- 공공데이터: [행안부 동물병원 조회서비스](https://www.data.go.kr/data/15154952/openapi.do) = POI 원천 확정. 좌표 EPSG:5174 → WGS84 변환 필요. 리뷰·영업시간 없음
- 유일한 후보: **Google Places API (New)** — rating/reviews/opening hours 있으나 (1) 국내 커버리지 낮음 (2) Enterprise(+Atmosphere) SKU (3) `place_id` 외 저장·캐시 금지, 표기 의무
- **결정**: 정렬 기준에 평가 미사용. 기본은 제공사 상세페이지 링크아웃(A), 상세 화면 한정 Google 온디맨드 조회(B, 미저장) 옵션. 자체 리뷰(C)는 유저 생긴 뒤
- 제공사 카테고리 문자열(`동물병원 > 안과` 등)로 "종류" 필터 해결 가능 → 수기 부담 감소. 보강 API는 결과 수 제한(네이버 5건) 때문에 카카오 로컬 우세
