## 리뷰를 통해 확정한 동작

1. 원천의 반려동물 허용보다 명시적인 강아지 불가(`dog_ok=false`)가 카드 상태에 우선한다.
2. 나이는 프로필 스냅샷의 기준일로 계산한다. 자정에 화면만 나이를 다시 계산하지 않는다.
   프로필을 새로 받으면 기준일도 갱신하고 이전 응답을 숨긴 채 재평가한다.
3. 검색 이름은 업종·반경·주차·반려견 변경에서 유지한다. 빈 문자열을 제출하면 이름 조건만 해제한다.
   주차는 필수 필터가 아닌 우선 정렬이고, 주차 정보가 없는 병원·약국에서는 적용하지 않는다.
4. 위치 권한이 없어도 선택한 반경을 보관하고 표시하며, 권한 허용 후 첫 요청에 적용한다.
5. 현재 검색이 실제로 기다리는 GPS만 결과 로딩을 결정한다. 이전 GPS 대기가 새 검색 결과를 가리지 않는다.
6. 위치 실패는 빈 결과가 아니다. 오류와 재시도를 제공하고 GPS를 다시 요청한다.
   네트워크 실패는 같은 검색 요청을 재실행한다.
7. 화면 밖의 늦은 이벤트를 차단하면서, 중단된 검색 의도를 별도로 보관해 재진입 시 복구한다.
8. 카드의 길찾기 재시도는 현재 시설과 현재 위치로 새 요청을 만든다.
9. 완료된 검색에 없는 카드의 펼침 키는 지운다. 로딩 중에는 유지하고 같은 시설이 돌아오면 보존한다.

## 남은 검증과 후속 기능

- 실제 로그인 계정으로 프로필 읽기·수정·검색까지 이어지는 종단 검증.
- 실기기 GPS·지도 마커 터치·스크롤·큰 글자·접근성·회전·키보드·외부 전화/지도 앱 실행.
- #154의 Robolectric 좌표 클릭은 액션을 전달하지 못했다. 버튼 연결은 의미 기반 클릭으로 검증했으며,
  중첩 스크롤 안에서 실제 버튼을 터치할 수 있는지는 실기기 확인이 남아 있다.
- 운영 기본 화면 전환 및 출시 서버의 계약 지원 확인. [실제 연결 기록](place-search-live-verification.md)은
  당시 개발 서버 지원과 출시 도메인 미지원 관측이며, 이번 문서 정리에서 서버를 다시 호출하지 않았다.
- 지역명·주소 지오코딩 검색, 앱의 실제 AI 조건 해석·비용 제어는 후속 구현이다.
  Geo의 기존 intent 실험이 앱 연결 완료를 의미하지 않는다.

이번 코드 리뷰 한 바퀴와 발견 문제 수정은 끝났지만, 위 검증까지 완료한 제품 출시 판정은 아니다.
