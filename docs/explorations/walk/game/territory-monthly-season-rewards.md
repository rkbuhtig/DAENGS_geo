# 점령 게임 — 첫 시즌 보상·72시간 유지·월간 시즌 합의

2026-09-09~10 사용자와 합의한 **첫 시즌 제품 정책**이다. 9월 10일 합의가 이전 보상
제안을 대체한다. 아래 배점·보상 단위·반복 탈취 허용은 확정이며 다시 미결로 취급하지 않는다.
`status: exploring`은 후속 구현·운영 설계가 남았다는 뜻이다. `implementation: none`은
이번 보상 분리·72시간 만료/연장·월간 자동 시작의 상태이며 기존 점령·인증 기반까지 없다는 뜻은 아니다.

이번 변경은 문서화다. 코드·DB·서버 설정·게임 활성화는 변경하지 않는다.
게임은 정책 구현·검증 후 별도로 활성화한다. 기존 저장 시즌의 규칙도 소급 변경하지 않는다.

## 1. 첫 시즌 운영 방향

영역을 넓게 확보하고 오래 유지하는 재미에 더해, 다른 회원에게서 빼앗는 경쟁도 보상한다.
첫 시즌은 반복 탈취로 점수를 쌓는 행동을 허용하고 실제 운영 결과를 관찰하기로 했다.

- 점수는 **기본 점령 보상 + 인증 탈취 보너스 + 보유 시간 점수**로 나눈다.
- 기본 점령 보상만 회원·장소·시즌별 누적 100점으로 제한한다.
- 다른 회원의 영역을 인증 탈취하면 이전 주인의 인증 여부와 관계없이 매번 20점을 추가한다.
- 시간당 미인증 2점, 인증 10점이며 동시 보유 계수는 넣지 않는다.
- 인증·미인증 모두 72시간 유지하며 유효한 현장 유지 행동으로 연장할 수 있다.
- 한국 시간 달력 월로 결산하고 다음 시즌을 자동 시작한다.

이전의 “모든 획득 보너스 시즌당 1회”, “인증 영역 탈취 50점 또는 20점으로 보상 종료”,
“미인증/인증 계수 분리 또는 합계 최대 2배” 제안은 채택하지 않는다.

## 2. 점령·인증·10분 보호

기존 [인증 우선 정책 v2](../../../territory-policy-v2.md)의 인증·탈취 판정을 유지하고,
보상과 유지 기간은 이 문서의 새 규칙으로 확장한다.

| 대상의 현재 상태 | 사진 없는 점령 | 다른 회원의 사진 인증 점령 |
|---|---|---|
| 빈 영역 | 미인증 점령 가능 | 인증 점령 가능 |
| 미인증 영역 | 다른 주인에게서 탈취 불가 | 즉시 탈취 가능 |
| 인증 영역, 10분 보호 중 | 탈취 불가 | 보호 종료 전 차단 |
| 인증 영역, 보호 종료 | 탈취 불가 | 새 사진 인증으로 탈취 가능 |

- 보호는 서버의 인증 확정 시점부터 10분이다. 종료 시각과 같으면 도전 가능하다.
- 자기 미인증 영역을 인증으로 강화할 때도 최초 인증 시점부터 10분 보호한다.
- 이미 인증된 자기 영역의 유지 재인증은 10분 보호를 다시 시작하지 않는다.
- 같은 산책에서 재도전할 수 있지만 새 도전·사진과 현재 상태에 대한 검증이 필요하다.
- 촬영 허가는 소유권 예약이 아니다. 확정 시점의 소유권 버전·시즌·만료 상태를 검증한다.

### 반복 탈취를 허용한다는 뜻

첫 시즌은 10분 보호 외에 탈취 보너스의 일일 한도, 회원 쌍별 제한, 추가 쿨타임을 넣지 않는다.
두 회원이 보호 종료 후 새 사진으로 번갈아 실제 탈취하면 매번 20점을 지급한다.
미인증 주인에게서 첫 인증 탈취는 대기 없이 가능하고, 이후 인증된 새 주인에게 10분 보호가 생긴다.
10분 보호가 담합을 막는다고 주장하는 것이 아니라, 사용자가 그 결과까지 허용한 운영 선택이다.

**정상적으로 성립한 별개의 탈취 반복과 동일 요청의 중복 처리는 다르다.** 회원 인증,
현장·사진 검증, 보호 시간, 원자적 소유권 변경, 요청/사진 callback 재시도의 멱등성은 유지한다.
같은 탈취 이벤트를 재전송해서 20점을 여러 번 받거나, 자기 회원의 강아지끼리 바꿔
탈취 보너스를 받는 것은 허용 범위가 아니다.

## 3. 기본 점령 보상과 탈취 보너스

### 기본 보상 자격은 회원 기준

기본 점령 보상 원장의 키는 **회원 ID + 장소 ID + 시즌 ID**다. 강아지 ID만으로 제한하지 않는다.
지급된 점수는 해당 행동에 참여한 강아지에게 귀속한다. 강아지를 바꿔도 회원의 남은 자격은 공유한다.
예를 들어 같은 회원의 A가 미인증으로 20점을 받고 B가 이후 인증하면 B에게 남은 80점을 지급하고,
A에게 지급한 20점은 그대로 남긴다. 기본 보상 합계는 100점이다.

- 미인증 획득의 기본 보상 목표는 20점, 인증 획득의 목표는 100점이다.
- 이번 기본 지급액 = `max(0, 이번 목표액 - 같은 회원·장소·시즌의 기본 기지급액)`.
- 탈취 보너스와 시간 점수는 위 기본 기지급액에 합산하지 않는다.
- 소유권 상실·만료·재점령·산책 종료·날짜 변경·강아지 변경으로 원장을 초기화하지 않는다.
- 다음 시즌에만 새 기본 보상 자격이 생기며 이전 시즌 원장은 보존한다.

### 행동별 지급

| 행동 | 기본 보상 | 탈취 보너스 |
|---|---:|---:|
| 빈 영역 미인증 점령 | 기본 누적 20점까지 차액 | 0 |
| 빈 영역 인증 점령 | 기본 누적 100점까지 차액 | 0 |
| 자기 미인증 영역 인증 강화 | 기본 누적 100점까지 차액 | 0 |
| 다른 회원의 미인증 영역 인증 탈취 | 기본 누적 100점까지 차액 | 20점 |
| 다른 회원의 인증 영역 인증 탈취 | 기본 누적 100점까지 차액 | 20점 |
| 자기 영역 유지·이미 인증된 영역 재인증 | 0 | 0 |

| 해당 장소의 내 기본 기지급액 | 이번 인증 탈취 지급액 | 이후 기본 기지급액 |
|---|---:|---:|
| 0점 | 100 + 20 = **120점** | 100점 |
| 20점 | 80 + 20 = **100점** | 100점 |
| 100점 | 0 + 20 = **20점** | 100점 |

이전 주인이 미인증이어도 같은 표를 적용한다. 이전 주인의 점수를 가져오는 것이 아니라
새 주인에게 지급하며, 이전 주인이 이미 얻은 점수는 차감하지 않는다.

만료된 빈 영역도 새 소유권 획득 시 위 회원별 기본 자격으로 계산한다. 해당 시즌에
다른 사람이 점령했던 이력만으로 기본 보상을 낮추지 않는다. 현재 주인이 없는 곳은 탈취가
아니므로 추가 20점은 없다. 기존 주인이 다시 획득해도 자신의 기본 지급 이력은 유지된다.
이 규칙에서 “그 시즌 아무도 먹지 않은 자리인지”를 별도의 배점 조건으로 두지 않는다.

## 4. 보유 시간 점수 — 계수 없음

```text
시간당 점수 = 미인증 보유 수 × 2점 + 인증 보유 수 × 10점
구간 시간 점수 = 구간 길이(시간) × 해당 구간의 시간당 점수
시즌 총점 = 기본 점령 보상 + 인증 탈취 보너스 + 보유 시간 점수
```

미인증 3개와 인증 2개를 한 시간 보유하면 26점이다. 인증 영역 하나를 72시간 계속
보유하면 시간 점수만 720점이다. 전체·종류별 동시 보유 계수를 모두 적용하지 않는다.

- 산책을 끝내거나 집에 돌아와도 소유권이 유효하면 적립한다. 4시간 제한·새벽 감점은 없다.
- 획득·탈취·인증 강화·만료·시즌 종료 시각으로 구간을 나눠 정산한다.
- 인증 이전 시간을 시간당 10점으로 소급 환산하지 않는다.
- 빼앗기거나 만료되면 그 시각에 적립을 멈추고, 되찾으면 이후 구간부터 재개한다.
- 백그라운드 작업이 늦어져도 만료/시즌 종료 이후의 점수는 생성하지 않는다.

## 5. 영역 유지 — 72시간과 현장 연장

- 인증·미인증 모두 점령 시점부터 72시간 유지한다.
- 현장 재방문 후 유효한 유지 행동을 하면 그 시점부터 72시간으로 갱신한다.
- 미인증 영역은 현장 영역표시로 유지하며, 인증 영역은 새 사진 인증이 필요하다.
- 자기 미인증 영역의 인증 강화는 기본 보상 차액 지급과 최초 인증 보호를 적용한다.
- 이미 인증된 자기 영역의 유지 재인증은 기본/탈취 보상 0점이고 기존 보호 종료 시각을 바꾸지 않는다.
- 단순 앱 실행·지도 조회·원격 버튼 클릭만으로 유지 기간을 연장하지 않는다.
- 실제 효력 종료는 **유지 만료와 시즌 종료 중 먼저 도래한 시각**이다. 72시간이 되면
  주인·인증·보호가 해제된 중립 영역으로 취급하며 기존 점수·보상 이력은 보존한다.
- 이미 만료된 뒤의 방문은 유지 연장이 아니라 빈 영역의 새 점령으로 판정한다.

10분 보호와 72시간 유지 만료는 별도 시각으로 관리해야 한다. 기존 `certified_ms`를
유지 재촬영 시각으로 덮어써서 보호까지 연장하는 구현은 이 정책에 맞지 않는다.
만료 경계와 지연 사진 확정의 경합 처리, 원자적 정산·갱신은 후속 구현에서 검증한다.

## 6. 월간 시즌과 자동 전환

`Asia/Seoul` 기준 매월 1일 00:00 이상 다음 달 1일 00:00 미만이 한 시즌이다.
고정 30일이 아니며 월별 일수·윤년·연도 변경을 따른다. 저장 시 UTC로 변환할 수 있다.

- 첫 실험 시즌만 실제 활성화 시각부터 다음 달 1일까지 짧게 운영하고 소급 점수를 만들지 않는다.
- 날짜 예시는 운영 예약이 아니다. 문서 수정이나 자동 전환 작업이 게임 OFF를 ON으로 바꾸지 않는다.
- **종료 시각까지 정산 → 최종 점수·순위·기록 보존 → 점령지 중립화 → 새 시즌 0점 시작**.
- 이전 시즌 결산 성공 후에만 새 시즌의 점령을 허용한다. 기본 보상 자격은 새 시즌 ID로 계산한다.
- 산책 기록·사진은 시즌 변경 때문에 삭제하지 않는다. 각 데이터의 기존 보존 정책은 유지한다.
- 지난 시즌의 늦은 사진 판정이 새 시즌의 점령·점수를 생성하면 안 된다.
- 결산이 늦어져도 달력상의 시즌 경계를 작업 실행 시각으로 밀지 않는다.
- 재시도·중복 스케줄러 실행 시 중복 정산·중복 활성 시즌·새 시즌 데이터 초기화가 없어야 한다.
- 전환 실패 시 미결산 상태에서 새 시즌 점령을 받지 않고, 정상화 후 안전하게 재개한다.

여러 달 중단한 뒤 누락 월을 기록하는 방식, 전환 지연 중 응답·복구 절차는 후속 운영 설계다.
잠금·멱등성 키·트랜잭션·스케줄러는 이 문서에서 구현 완료로 표시하지 않는다.

## 7. UI 및 후속 범위

선택하거나 가까이 접근한 전봇대의 범위를 표시한다. 주인 카드에서 강아지 사진·이름과
그 강아지의 점수를 한 묶음으로 읽히게 한다. ID 문자열을 주된 이름표로 노출하지 않지만
내부 식별은 ID로 유지한다. 공유 점령 상태와 개인 산책·사진 원본의 공개 범위는 구분한다.

전봇대 북마크·한도·알림은 후속이다. 동네 순위 범위·칭호는
[기존 검토 계약](../../../contracts/territory-ranking-titles.md)에서 별도로 닫는다.
이 문서는 해당 범위를 확정하거나 구현하지 않는다.

[#244](https://github.com/SAJOYO/DAENGS_APP/pull/244)는 별도 구현이다. API 배포·인증 v2
마이그레이션·지도 표시가 이번 보상 정책 구현이나 게임 활성화를 뜻하지 않는다.
2026-09-09 테스트 앱 조회의 시즌/주인 요약 응답은 503 `activity_disabled`였다.
현재 배포 설정·DB 상태를 이 문서 변경 과정에서 재검증하지 않았다.

작업 순서:

1. 정책 버전과 회원 기본 보상 원장·탈취 이벤트·강아지별 점수 귀속·만료 필드를 설계한다.
2. GEO에서 기본 차액·매 탈취 20점·2/10 시간 정산·72시간 만료/연장을 구현·검증한다.
3. 월간 자동 전환·실패 복구를 구현하고 DEV 스키마/마이그레이션·정산 서비스로 승격한다.
4. APP 주인 점수 카드·보상 내역·유지 만료/연장 표시를 연결한다.
5. 개발 서버 설정·워커·스케줄러와 앱 액션 활성화를 맞춰 첫 실험 시즌을 연다.

최소 검증 시나리오:

- 빈 영역의 미인증 20 → 자기 인증 강화 80 → 자기 재인증 0.
- 첫 인증 탈취 120 → 재탈취 20, 기본 20점 보유자의 인증 탈취 100.
- 이전 주인이 미인증/인증인 두 경우 모두 탈취 보너스 20.
- 같은 회원의 강아지 변경으로 기본 100점 한도 우회/자기 탈취 보너스 발생 없음.
- 서로 다른 회원의 보호 종료 후 반복 탈취는 매번 20, 같은 이벤트 재시도는 추가 지급 0.
- 인증 전후 시간당 2/10 정산, 보유 수 증가에도 계수 없음.
- 72시간 직전/정각, 만료 후 재점령, 유지 연장에 의한 보상/보호 리셋 없음.
- 만료되어도 기본 지급 이력 유지, 만료 처리 지연 중 초과 시간 점수 없음.
- 월말·윤년·연말·첫 단축 시즌, 실패 후 전환 재시도, 늦은 사진 판정과 새 시즌 데이터 보존.
