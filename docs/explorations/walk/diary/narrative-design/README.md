# 산책 장면 서술 — 기획 경위와 작업 인계

**사용자가 돌아볼 수 있는 장면 하나를 완성하는 것이 우선이다.** 이 묶음은 결론뿐 아니라
그 결론에 도달하기까지의 문제, 사용자 지적, 철회한 제안, 실제 실험의 한계를 남긴다.
목적은 다음 에이전트가 자료 수집·슬롯 구현·검증 문구를 서술 품질의 성과로 착각하거나,
이미 거절된 전체 세션 이해·시설 소개·대체 API 실험을 다시 시작하지 않게 하는 것이다.

현재 기획의 짧은 기준은 [상위 기획](../plan.md)이다. 아래 상세 문서와 함께 읽는다.
2026-09-12 대화에서 채택한 방향이며 **현재 코드와 프롬프트의 반영 완료를 뜻하지 않는다.**

## 현재 결정의 중심

1. **장면은 독립된 서브 일기다.** 전체 산책을 먼저 이해하거나 앞뒤 장면을 연결해야 생성할 수 있는 구조를 두지 않는다.
2. **서술의 골격은 어디서 · 누가 · 무엇을 · 어떻게 · 환경 α다.** 이것은 의미의 역할이다. 항상 다섯 항목을 채우는 양식이나 고정 문장 템플릿이 아니다.
3. **장면 서술과 행동 서술을 구별한다.** 공간·환경을 그리는 시선과, 반려견의 행동을 가까이서 담는 시선은 다르다. 최종 글은 자연스럽게 함께 읽힐 수 있다.
4. **특별한 순간은 사용자가 직접 쓰는 별도 장면이다.** 자유 서술 본문에 AI가 관여하지 않고, 해당 순간의 공간·환경 정보만 별도로 제공한다.
5. **시간과 장면 순번을 자유 추론 재료로 주지 않는다.** 시스템의 판정·정렬에는 남기되 계절감·시간 체감·공백을 넘는 연속성의 단서로 넘기지 않는다.
6. **슬롯은 사용 가능한 사실의 범위를 남긴다.** 잘못된 재료를 조건으로 제외하되, 모든 파트를 채우거나 시설 하나를 반드시 말하도록 강제하지 않는다.
7. **실제 지정 API의 응답부터 확인한다.** 그 자료를 같은 골격에 분류하고 다른 좌표에도 적용한 다음, 실제 LLM 입력·프롬프트·출력으로 서술을 평가한다.
8. **공개한 결과와 사용자 편집은 자동으로 교체하지 않는다.** 전체 일기는 장면과 원본·추가 세션 자료를 읽는 별도의 후속 생성이다.

## 결정의 강도와 출처

이 문서 묶음에서 다음 표기를 구별한다.

| 구분 | 뜻 | 다음 작업에서의 취급 |
| --- | --- | --- |
| 제품 원칙 | 사용자가 명시적으로 정했거나 반복 지적으로 확정한 방향 | 구현 편의나 이전 문서로 뒤집지 않는다 |
| 원칙의 적용 기준 | 제품 원칙이 구체적인 사례에 요구하는 해석 | 근거와 이유를 확인하며 적용한다 |
| 기존 구현·실행값 | 특정 코드·실험에서 실제 사용한 방식·숫자 | 재현용이다. 최적값이나 현 기획 전체로 승격하지 않는다 |
| 구현 제안 | 원칙을 실현하기 위해 에이전트가 제안한 수단 | 사용자 확정 사항처럼 보고하지 않는다 |
| 미결·미검증 | 아직 실제 자료·출력·연결로 확인하지 못한 부분 | 성공을 전제하지 말고 다음 검증 대상으로 남긴다 |
| 철회·중단 | 이후 사용자 지적으로 현재 경로에서 제거한 접근 | 편의상 자동 재개하거나 다른 이름으로 되살리지 않는다 |

충돌 시 최신 사용자 결정이 이전 제안·실험보다 우선한다. 과거 연구 문서는 당시 사실을
보존하기 위해 남아 있다. 거기에 시간순 맥락이나 메모 재서술이 있다고 현재 계약으로 복사하지 않는다.

## 지금 멈춘 위치

이 문서 작성 직전 작업은 **지정 공공 API의 실제 호출을 확인하지 못한 상태에서 중단**됐다.
사용자가 제공한 다른 환경의 성공 보고와 이 Work 환경의 `HTTP 502 / Connection refused`는
서로 다른 실행 기록이다. 인증키 오류나 공급자 전체 장애로 결론 내리지 않았다.

Kakao의 실제 응답을 대신 받아 분류했던 시도는 사용자가 요구한 공공 API 실험의 대체물로
인정되지 않았다. 새 서술 골격으로 공공 API 자료를 끝까지 연결한 실제 LLM 실험도 아직 없다.
이번 작업은 그 상태와 기획을 기록하는 일이다. API·모델 호출을 재개한 작업이 아니다.

## 저장소에서의 위치

기획·연구 원본은 GEO의 이 경로에 둔다. 운영 서버 변경은 DEV, Android 변경은 APP에서 한다.
저장소 전체를 복사하거나 GEO에 운영 변경을 역동기화하는 지시는 아니다.

장면 우선 기획의 첫 문서 반영인 GEO #265, DEV #482, APP #340은 2026-09-12에 병합됐다.
그 후 이어진 **특별한 순간 / 행동 서술 / 참여 대상 / 무엇을 / 지정 API 실험** 결정까지
포함하는 상세 인계가 이 묶음이다. 이전 문서 커밋을 가리키는 링크는 그 시점의 기록이다.
정확한 기준 커밋과 링크는 [근거 원장](06-conversation-evidence.md)에 있다.
