# 실제 모델 출력 원문 모음

이 문서는 **미채택·실패를 포함한 당시 응답 기록**이다. 현재 작성 지시나 채택 문장집이 아니다.
사람이 고친 예문 대신 실제 결과를 확인할 수 있도록, 원응답에서 `background` 또는 `body`만 그대로 추출했다.
첫 세 실행은 배경 필드이고 이후 실행은 비교용 전체 본문이다. 같지 않은 출력 계약을 구별해 읽는다.
숫자는 이 문서의 응답 배열 위치이며 현재 모델 입력에 순번을 넣으라는 뜻이 아니다.
평가·입력 맥락·중단 상태는 [실험 기록](04-experiments-and-limitations.md)에 있다.

응답 없는 run-10/11/13은 문장을 만들어 채우지 않았다.
원본 파일 해시는 원래 JSON 파일 바이트의 SHA-256이다. 이 추출 문서는 ID·사용량·원본 동선 전체를 복사하지 않는다.
