# 미시 판정층 — 결정 #7 의 확장이지 새 교리가 아니다

미시 사건을 **누가 어떻게 판정하는가**의 갈래다. 2026-08-28 논의의 착지점이고,
판정 기준층을 관측·저장과 분리한다는 방침 아래에 있다.

출발점부터 박아 둔다: **이 문서는 결정 #7("판정은 코드, LLM 은 서술/파싱만 — 보상
인플레·환각 방지", 2026-08-19)의 미시판이다.** 8월의 논의가 독립적으로 같은 자리에
도착했다 — 그 연속성이 이 갈래의 정당성이다. 새로 추가되는 것은 딱 하나, 좁게 게이트된
escalation 슬롯이고, 채택하려면 #7 의 **보이는 개정**이어야 한다.

## 판정은 4층이다

    L1  관측            walk_micro_observation · speed_profile (리비전 0020)
    L2  결정론 지표      excess-time · low-motion 질량 · path/net · 반복성 · 분모
    L3  룰/정책          Evidence gate — 발언 가능성 판정
    L4  escalation      의미적 애매함의 해석 (LLM — 이 레포 밖)

### L1 — LLM 금지. 애초에 판정도 금지

리비전 0020 이 이 층이다. `slow`(관측된 저속)와 `gap`(비관측 경과)을 가르고, "체류였나"
는 묻지 않는다. 여기 판정이 들어오면 [memory-engine](memory-engine.md) 원칙 6("캡슐은
판단을 얼리지 않는다")이 무너진다.

### L2 — 계산 가능한 것은 계산한다

지표 후보(occupancy · low-motion · excess-time · prominence)와 자리별 축(노출 · 반복성 ·
강도, 분모는 체류를 뺀 통과 기준). 어느 후보가 이기는지는 미정이다 — fixture generation 2
위의 매트릭스 실험이 정한다 ([repeated-dwell-area](repeated-dwell-area.md) M3).

### L3 — 룰은 행동의 의미가 아니라 발언 가능성을 판정한다

    묻는 것       "이 정도면 반복 행동 자리라고 **말할 근거가 있는가**"
    안 묻는 것    "개가 냄새를 좋아하는가"  — 데이터가 보증 못 하는 문장

단일 문턱(`excess > 30 → dog_place`)이 아니라 게이트 묶음이다: 관측 품질 · 반복성 ·
gap 오염 · 한 산책 독점 여부 · 구조적 설명의 강도. **구체 문턱값은 여기 안 적는다** —
그건 이 갈래가 정할 것이 아니라 합성 정답지(E·F 포함) 위에서 룰의 확신 구간과 실패
구간을 **그린 뒤에** 정한다. 지금 값을 적으면 그 실험이 답을 확인하는 절차로 전락한다.

### L4 — escalation. 이 레포에는 없다

LLM 은 이 레포에 안 달린다(#7 · 팀 챗봇이 주체, 레포는 tool 묶음). 그래서 이 레포에서
L4 는 코드가 아니라 **정직한 수출**이다: Evidence Packet 에
`deterministic_judgment: clear | insufficient | ambiguous` 와 경쟁 해석 목록을 실어
내보내는 것까지. 그걸 받아 LLM 을 부를지는 메인 서비스의 일이다.

## LLM 호출 구간은 가운데다

    근거 낮음                 중간 — 해석 가치 있는 애매함              근거 높음
       │                            │                                │
     침묵                      LLM 검토                            룰 판정

- 근거가 약하면(1회 방문 · 12초 · accuracy 25m) LLM 을 부르면 안 된다 — 없는 의미를
  만들어 줄 가능성만 커진다. `insufficient` 로 침묵
- 근거가 강하면(35회 방문 · 29회 동일 위치 저속 · gap 없음) 부를 필요가 없다 — 룰이
  판정하고 LLM 은 문장만 쓴다
- **LLM 은 uncertainty 의 쓰레기통이 아니라, 해석 가치가 있는 ambiguity 만 받는다**

### 애매함에는 두 종류가 있고, LLM 몫은 한쪽뿐이다

여기가 이 갈래에서 제일 넘어지기 쉬운 자리다.

| 종류 | 정의 | 출구 |
|---|---|---|
| **정보적 부족** | 가진 feature 로는 해석들이 원리적으로 안 갈린다 (M2 의 "대비만으로 A/B 안 갈림"이 이것) | **침묵, 또는 측정 백로그** (새 축을 재라) |
| **의미적 애매함** | 데이터는 충분한데 프레이밍이 여럿이다 — 근거 충돌의 해석, 여러 축의 한 문장 압축, 사용자 의미와의 조정 | **LLM** |

정보적 부족을 LLM 에 넘기면 어떻게 되나 — **LLM 도 같은 Packet 을 읽는다. 룰보다 더
아는 게 없다.** 나오는 것은 판단이 아니라 유창하게 포장된 동전 던지기고, 유창해서 더
위험하다. 합성 실험이 그려 줄 "룰의 실패 지도"는 LLM 호출 조건표가 아니라 이 두 종류를
가르는 **분류표**다.

## Escalation 계약 — 넷을 전부 만족할 때만

    1  deterministic gate 통과            말할 만한 Evidence 는 있다
    2  둘 이상의 경쟁 해석                 단, 추가 데이터로 갈리는 종류면 LLM 이 아니라
                                          측정 백로그로 보낸다 (위 표)
    3  해석이 제품 표면을 실제로 바꾼다     내부 score 차이면 호출 안 함
    4  허용 문장 경계를 Evidence 로 제한 가능

## 판정 LLM 의 출력은 편집층 전용이다

호출이 드물어도, 출력이 파생층(자리 사다리 단계 · Place 상태)을 바꾸면 **LLM 이
검출기다** — 드물게 틀리는 검출기일 뿐이다. 그래서:

> **LLM 판정의 출력은 편집층(무엇을 어떻게 말할까)에만 쓴다.
> 파생층은 결정론 게이트나 사용자 확인만 바꾼다.**

애매한 자리는 데이터에서 계속 애매한 채로 남고, LLM 이 고르는 것은 헤지된 문장 대
침묵뿐이다. `allowed_statement` 는 LLM 의 자기 신고로 끝나지 않는다 — Packet 에 없는
원자를 인용한 문장은 **출력 스키마 검증에서 탈락**한다. 환각 방지를 프롬프트가 아니라
검증기가 한다.

## 표현 언어는 두 단계다

판정 결과가 문장이 될 때의 규칙. [behavior-anchor](behavior-anchor.md) 와 한 쌍이다.

    기계가 파악한 것    뭉뚱그려 나간다     "여기 오면 천천히 머무는 편이에요"
    증언이 붙은 것      확정으로 나간다     "냄새 맡았어요"  (anchor 가 있는 사건만)

측정은 자리 단위 반복 주장을 보증하고, 사람의 증언은 사건 단위 주장을 보증한다.
기계 판정이 아무리 확신해도 확정 어미를 얻지 못한다 — 확신은 내부 값이고, 확정은
증언의 권리다.

## 판정 LLM 과 나레이션 LLM 은 다르다

    판정 LLM       드물게 — 위 계약을 전부 통과할 때만
    나레이션 LLM    흔하게 — 이미 판정된 Evidence 를 문장으로

나레이션은 원래부터 소비자(#7 의 "서술")의 일이었고 이 갈래가 건드리지 않는다.

## 안 하는 것 · 아직 모르는 것

- **문턱값 · escalation 조건값** — fixture generation 2 + 지표 매트릭스가 룰의 실패
  지도를 그린 뒤. 지금 정하면 실험이 요식이 된다
- **Evidence Packet 의 확정 스키마** — 방향만: 자리별 축(노출·반복성·강도) · 관측 품질 ·
  gap 비율 · world context 원자 · 경쟁 해석 · deterministic_judgment. 확정은
  walk-capsule 계약과 함께
- **캘리브레이션**(사용자 anchor 로 룰을 개인화) — anchor 데이터가 생긴 뒤, 행동별로
  ([behavior-anchor](behavior-anchor.md) 참조)
- 채택 시 필요한 결정: #7 의 개정(escalation 슬롯 + 편집층 전용 조항)
