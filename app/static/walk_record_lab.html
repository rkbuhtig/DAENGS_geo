실험 준비 중

기존 GPS lab에서 경로와 센서 조건 편집하기

지도에서 경로를 편집한 뒤 아래 버튼으로 가져오세요. 현재 기록은 새 시나리오로 교체됩니다.

1. 가상 산책 기록

실선: 수용된 GPS 구간 · 초록 원: 기록 · 보라 사각형: 환경 조회 · 주황 원: 현재 전달된 GPS. 배경은 축척도이며 도로 지도가 아닙니다.

시간을 옮겨 장면을 기록할 수 있어요. 행동 핀은 도착한 GPS가 15초 이내·정확도 50m 이내일 때만 저장됩니다. 메모는 위치 없이도 남길 수 있어요.

2. 산책 종료 후 비교

액션 핀 → 평소 대비 이동 변화 → 세션 속도 변화 → 가장 큰 빈 거리 구간 순으로 선택합니다. 최소 목표 달성 후에도 긴 빈 구간을 보충하며 최대 8구간입니다. 실제 조회는 종료 버튼에서만 실행합니다.

실험의 근거와 한계
행동·경로는 합성입니다. 주변 상가는 등록 자료이며 방문이나 혼잡도를 뜻하지 않습니다. 공원은 강남구 제공 자료의 대표점, 하천은 표준데이터의 시점 좌표만 비교합니다. 조회 실패·부분 수집·캐시 없음은 시설이 없다는 뜻이 아닙니다. 메모는 행동 프로필에 포함되지 않습니다.
SGIS 경계나 하천 형상 파일 없이 실행합니다. 기존 스토리보드의 지역 구간 구분은 이번 실험에 포함되지 않습니다. API 키와 DB 정보는 브라우저나 내보내기 파일에 전달되지 않습니다.
